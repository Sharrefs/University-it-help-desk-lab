# University IT Help Desk Lab

## Project Overview
This project simulates a Tier 1 IT help desk scenario in a university environment. It demonstrates how a technician gathers information, troubleshoots a reported issue, documents findings, escalates an incident, and verifies resolution.

## Scenario
A student reported being unable to access the university student portal.

## Troubleshooting Performed
- Verified network interface and IP configuration.
- Tested local gateway connectivity using `ping`.
- Tested Internet connectivity using `ping`.
- Tested DNS resolution using `nslookup`.
- Gathered additional information from the user.
- Determined that multiple students and devices were affected.
- Identified evidence suggesting a university service outage.

## Resolution
The incident was escalated to the university IT application/services team. The team resolved an application-server issue, and the student confirmed that the portal was accessible again.

## Skills Practiced
- Tier 1 troubleshooting
- Basic network diagnostics
- DNS troubleshooting
- User communication and information gathering
- Incident documentation
- Problem isolation and escalation
- Knowledge-base documentation
- Resolution verification

## Disclaimer
This is an educational simulation. The student portal outage and escalation response were simulated for practice; no actual university service was investigated or repaired.
